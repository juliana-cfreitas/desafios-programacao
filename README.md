Resumo dos Conceitos Praticados

Durante as atividades no freeCodeCamp, foram praticados conceitos básicos de HTML e CSS, incluindo estrutura de páginas, títulos, parágrafos, links, imagens, listas e seções.

As atividades contribuíram para desenvolver a lógica de programação e ampliar o contato com diferentes linguagens e tecnologias utilizadas no desenvolvimento de software.
